# My Homelab
## Getting Started
### Requirements
- Docker 

### Installation
`docker compose up -d`

## Current Services
- `Anchor`: For note-taking
- `Immich`: For image management
- `Homepage`: Services dashboard
- `Vaultwarden`: Password management 

## Adding a Service 
- Update `compose.yaml` 
- Update `homepage/config/services.yaml`
- Update `README/Current Services`
